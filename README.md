# Repository overview

This repository contains the raw quantum-device data and supporting Python code associated with the manuscript available at https://doi.org/10.48550/arXiv.2510.13577.

The repository is organized according to the arXiv version of the manuscript.

## Directory structure

```text
v1/
  fig1/
  fig2/
  ...

v2/
  data/
  code/
```

- `v1/` corresponds to arXiv version 1 of the manuscript.
- `v2/data/` contains the data files corresponding to arXiv version 2 of the manuscript.
- `v2/code/` contains Python code used to construct the quantum circuits and to support the analysis and figure generation for arXiv version 2.

Because the manuscript evolved between versions, figure numbers and figure contents may differ substantially between `v1` and `v2`.

## Notes on versioning

The `v1` and `v2` directories are provided to preserve the correspondence between repository contents and different versions of the manuscript.

Please note that files associated with the same figure number in different versions are not necessarily equivalent, as figures may have been substantially revised or replaced during manuscript updates.
